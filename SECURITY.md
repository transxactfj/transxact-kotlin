# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Email **security@transxact.io** with a description,
reproduction steps and the affected version. We aim to acknowledge reports within 3 business days.

## Scope

This SDK is server-side only. Never put an `sk_test_...` / `sk_live_...` key in a mobile or browser app.
If you suspect a key has leaked, roll it from the Transxact dashboard immediately.
